## Mes projets

- **[StageFlow](https://github.com/khadidja-ahmat/StageFlow)** : application de suivi de candidatures de stage et d'alternance. API REST Spring Boot (Java 21) et MySQL, interface React, tests JUnit et Vitest, intégration continue GitHub Actions.
- **[ChariPHP](https://github.com/khadidja-ahmat/ChariPHP)** : générateur de back-office en PHP natif que j'ai écrit (connexion, tableau de bord, modules de gestion en AJAX pour chaque table MySQL).

- **[Clinique Espoir – Laravel](https://github.com/khadidja-ahmat/site-web-clinique_espoir)** : gestion d'une clinique (patients, rendez-vous, ordonnances) avec authentification, API et tests.
- **[Clinique Espoir – PHP natif](https://github.com/khadidja-ahmat/Site-web-clinique-Espoir-ChariPHP)** : la même clinique, avec un back-office généré par ChariPHP.
- **[Site de la CNAS](https://github.com/khadidja-ahmat/Site_web_CNAS)** : site de la Caisse Nationale d'Assurance Santé, site visiteur en Laravel et administration en PHP natif.
